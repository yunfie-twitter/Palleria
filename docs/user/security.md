# アプリロックと電卓偽装

Palleria には、プライベートな鑑賞を守るためのセキュリティ機能が備わっています。

---

## アプリロック

- **PIN コード**: 6 桁の暗証番号を設定してアプリ起動時にロックをかけられます。
- **指紋・顔認証**: スマホの指紋センサーや顔認証でスムーズにロック解除できます。
- **自動ロック**: アプリを閉じてから指定した時間（即時〜10分）が経つと、自動的にロックがかかります。

---

## 電卓偽装機能

アプリの見た目を「本物の電卓」に化けさせる機能です。表示を切り替える機能で、データの暗号化や端末自体の保護を代替するものではありません。

- **本物として計算できる電卓**: 実際に入力して計算ができる偽装画面が表示されます。
- **秘密の解除方法**: 設定した番号を入力して `=` ボタンを押すことで、はじめて Palleria 本体の画面が開きます。
- **アイコンと名前の変更**: ホーム画面上のアプリ名も「電卓」という名前に変わります。

---

## スクリーンショット保護

設定から画面保護を有効にすると、スクリーンショットの撮影や画面録画を防止できます。また、スマホのタスク切替画面でアプリの中身が映らないように内容を隠す設定があります。
