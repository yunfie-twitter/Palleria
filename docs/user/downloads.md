# AppTekaで配信されているアプリについて

::: warning 注意喚起
現在、サードパーティのアプリ配信サイト「AppTeka」にて **Palleria** が掲載・配信されておりますが、**これらは開発者（公式）が提供・許可したものではありません。**
:::

非公式の配布サイトからダウンロードしたファイル（APK）には、悪意のある改ざんやマルウェアの混入、あるいは古いバージョンのまま放置されているなどのセキュリティリスクが伴います。

安全にご利用いただくため、アプリの新規インストールやアップデートは、必ず以下の**公式配布元**（F-Droid リポジトリ、または GitHub Releases）から行っていただきますようお願いいたします。

## 公式配布元のご案内

詳しいインストール手順については、以下のガイドページをご確認ください。

- **公式インストールガイド**: [アプリの入手とインストール](/user/installation)
- **公式 F-Droid リポジトリ**: `https://palleria
  .yunfie.date/repo/`

::: info 免責事項
非公式の配布元から入手したアプリの利用によって生じたトラブルや損害について、開発者は一切の責任を負いかねますのであらかじめご了承ください。
:::
