# ライブ壁紙とウィジェット

## 壁紙の画像ソース

ライブ壁紙の画像ソースは、**保存済み画像**または**選択した端末内フォルダ**です。Pixivのブックマークやタグを直接検索して壁紙にする設定ではありません。使用したい作品を先に保存するか、フォルダへの読み取りを許可してください。

切り替え契機・時間間隔、並び順、拡大方法、背景、クロスフェード、センシティブ作品の除外を設定できます。別の壁紙プレイリスト処理には、保存画像を約6時間間隔の非厳密アラームで切り替える実装もあります。

ライブ壁紙は、アプリがデスクトップ環境・WSA・HyperOS端末と判定した場合には無効になります。

## イラストウィジェット

1. ホームアプリのウィジェット一覧からPalleriaのイラストウィジェットを追加します。
2. Palleriaへログインし、設定画面で作品と表示するページを選びます。
3. 適用すると選択画像を端末内へ保持して表示します。画像をタップすると該当作品を開きます。

画像ファイルが失われた場合は再設定の案内が表示されます。表示が空白になった場合は、ウィジェットをタップして作品を選び直してください。プライバシーモード中は作品画像を表示しません。

## ランキングウィジェット

デイリーランキングからフィルター適用後の**最大3作品**を表示します。TOP 10をスライドする形式ではありません。ログイン状態が必要で、プライバシーモード中は取得・表示が制限されます。

ウィジェットのサイズや配置操作はホームアプリによって異なります。
