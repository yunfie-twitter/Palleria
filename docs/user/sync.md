# 端末間データ同期（PallaSync）

PallaSyncは、同じチェーンに参加した端末間でコレクションを同期する機能です。アプリ全体のバックアップや、Pixivアカウントへのログイン共有ではありません。

## 同期するデータ

実装上の対象は、お気に入りタグ、検索履歴、ミュートしたタグ・ユーザー・作品、既読フィード作品、閲覧履歴です。テーマなどすべての設定、認証トークン、保存済み画像ファイルを一括同期するものではありません。Pixiv上のブックマークやフォローはPixivアカウント側で管理されます。

## 端末をつなぐ

1. 最初の端末で設定の「PallaSync」を開き、同期サーバーのURLを確認して有効化します。新しいチェーンが作成されます。
2. 「端末をペアリング」から同期コードの表示画面を開きます。
3. 追加する端末で同じサーバーを指定し、ペアリング画面の同期コード入力、またはQRコード読み取りを使って既存チェーンに参加します。
4. 参加端末の一覧と同期ログを確認します。必要に応じて「今すぐ同期」を実行できます。

各端末で個別に新しいチェーンを作成しても、同じ同期先にはなりません。同期コードはチェーンへ参加するための秘密情報なので、公開しないでください。

## 暗号化と解除

送信するレコードの本文は端末側で暗号化します。現在のプロトコルは2.1で、本文にはXChaCha20-Poly1305を使用し、旧2.0形式も読み取ります。チェーンIDなどの配送用情報まで非公開になる仕組みではありません。

「チェーンから退出」はこの端末を切り離す操作で、「チェーンを削除」は同期先のチェーンを削除する操作です。確認ダイアログの対象を確かめてください。

技術的な保存場所・暗号処理は[PallaSync同期エンジン](/dev/pallasync-engine)を参照してください。
