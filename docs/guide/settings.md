# 設定とプライバシー

## 表示とテーマ

アプリの外観と画像表示を好みに合わせて調整できます。

- ライト・ダークテーマ
- AMOLED向けの黒基調テーマ
- 表示言語
- 画像品質
- 一覧や閲覧画面の表示設定

高画質を選ぶと通信量と保存容量が増えることがあります。モバイル回線ではデータ使用量に注意してください。

## Feature Flag

設定のFeature Flagから、次の表示機能を個別に有効化できます。初期状態では無効です。

- **トップスクロールのぼかし効果**: ホーム、ランキング、ブックマーク、検索トップ、プロフィールで、スクロール中のヘッダー背景をぼかします。文字とボタンは鮮明に表示します。Android 12未満では半透明背景を使用します。
- **ナビゲーションバーをアイコンのみにする**: 標準の下部ナビゲーションのラベルを非表示にします。読み上げ用の名前は保持します。フローティングナビゲーションは元からアイコンのみです。
- **高速スクロール時の描画軽量化**: 高速スクロール中はヘッダーのぼかし、プレビューの影、一覧の配置アニメーションと読み込み時のシマーを抑制します。スクロールが落ち着くと元に戻ります。
- **コマンドパレット**: ログイン後に`Ctrl + K`で開きます。検索語を入力するか、ホーム・ランキング・ブックマーク・小説・設定への移動、テーマ変更を選択できます。上下キーで選択、Enterで実行、Escで閉じます。ロック中は使用できません。

グリッドのピンチによる列数変更では、作品と小説カードの配置・高さをアニメーションさせます。描画軽量化フラグが有効で、高速スクロールしている間は省略します。

3ボタンナビゲーションの領域は、縦画面の下端・横画面の側面ともアプリの表示領域から確保します。

## 通信

環境に応じてPixiv画像プロキシなどのネットワーク設定を変更できます。接続先を変更する場合は、信頼できるサービスかを確認してください。

## ミュート

見たくないユーザー、タグ、作品をミュートできます。ミュート条件は設定から確認・解除できます。

## バックアップと復元

対応する設定やデータをJSONへ書き出し、あとで復元できます。

::: warning バックアップの取り扱い
バックアップには利用状況や設定が含まれる可能性があります。共有ストレージやクラウドへ保存する場合は、公開範囲を確認してください。
:::

## セキュリティ

- PINロック
- 生体認証
- セキュアウィンドウ
- スクリーンショット保護
- アプリアイコンの切り替え

生体認証の利用可否は、端末のハードウェアとAndroid設定に依存します。PINを忘れないよう、安全な方法で管理してください。

## データを守るために

1. APKは案内している公式配布元から取得する
2. リフレッシュトークンを他人へ渡さない
3. 端末の画面ロックを有効にする
4. OSとPalleriaを最新の状態に保つ
5. 不要になったバックアップを安全に削除する
