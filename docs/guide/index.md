# Palleriaを使う

Palleriaは、イラスト・マンガ・小説を快適に閲覧できるオープンソースのAndroid向けPixivクライアントです。このガイドでは、インストールから基本的な使い方までを案内します。

::: warning 非公式クライアントです
PalleriaはPixiv Inc.とは関係のない非公式アプリです。利用にあたっては、Pixivの利用規約と適用される法令を守ってください。
:::

## 最初の3ステップ

1. [Palleriaをインストールする](./install)
2. [Pixivアカウントでログインする](./login)
3. ホーム、検索、ランキングから作品を探す

## できること

- イラスト、マンガ、小説の閲覧
- 作品・タグ・ユーザーの検索
- ブックマークとフォローの管理
- 画像のダウンロードとダウンロードキューの管理
- 閲覧履歴・検索履歴の確認
- ダークテーマ、AMOLEDテーマ、画像品質などのカスタマイズ
- PINロック、生体認証、スクリーンショット保護などのプライバシー設定

詳しい内容は[主な機能](./features)を参照してください。

## 動作環境

- Android 7.0（API 24）以降
- Pixivアカウント
- インターネット接続

端末やAndroidのバージョンによって、一部の機能や権限表示が異なる場合があります。
