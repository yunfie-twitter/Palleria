# よくある質問

## PalleriaはPixiv公式アプリですか？

いいえ。Palleriaはコミュニティによって開発されているオープンソースの非公式クライアントで、Pixiv Inc.とは関係ありません。

## 対応しているAndroidバージョンは？

現在のソースコードではAndroid 7.0（API 24）以降を対象としています。端末固有の制限によって、一部機能を利用できない場合があります。

## Google Playからインストールできますか？

このドキュメントで案内している配布元は、PalleriaのF-DroidリポジトリとGitHub Releasesです。詳しくは[インストール](./install)を参照してください。

## 画像が表示されません

次の順に確認してください。

1. ほかのネットワークへ切り替える
2. VPN、独自DNS、広告ブロッカーを確認する
3. 設定している画像プロキシを確認する
4. アプリを最新版へ更新する

Pixiv側の障害や仕様変更によって、一時的に利用できない場合もあります。

## ログイン情報をIssueに書いてもよいですか？

書かないでください。パスワード、Cookie、リフレッシュトークン、個人情報をIssueやログへ含めないでください。問題報告では、アプリのバージョン、Androidのバージョン、再現手順、機密情報を除いたエラー内容を伝えてください。

## 不具合や要望はどこへ報告しますか？

[GitHub Issues](https://github.com/yunfie-twitter/Palleria/issues)を利用してください。既存のIssueを検索してから、新しいIssueを作成してください。
