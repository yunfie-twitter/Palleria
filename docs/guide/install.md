# インストール

PalleriaはF-Droidリポジトリ、またはGitHub Releasesから入手できます。自動更新を利用しやすいF-Droid経由がおすすめです。

## F-Droidからインストール

次のリポジトリをF-Droidクライアントに追加します。

```text
https://palleria.yunfie.date/repo/
```

[F-Droidにリポジトリを追加](https://palleria.yunfie.date/repo?fingerprint=28A7F64F373AC1AD5FBB4822870E2E07B2B204C7EC71E58CE40F9D54EF2727D9){.vp-button}

1. リンクをAndroid端末で開きます。
2. 使用するF-Droidクライアントを選び、リポジトリを追加します。
3. リポジトリの更新が終わったら「Palleria」を検索します。
4. アプリを選択してインストールします。

::: tip リポジトリが表示されない場合
F-Droidの「リポジトリ」画面で、Palleria Dev Repositoryが有効になっているか確認し、手動で更新してください。
:::

## GitHub Releasesからインストール

[最新リリースを開く](https://github.com/yunfie-twitter/Palleria/releases/latest)からAPKをダウンロードします。

1. 最新リリースのAssetsからAPKファイルを選びます。
2. ダウンロードしたAPKを開きます。
3. Androidの案内に従い、必要な場合はブラウザまたはファイルアプリに「不明なアプリのインストール」を一時的に許可します。
4. インストール完了後、不要なら許可を戻します。

::: warning 配布元を確認してください
APKはこのプロジェクトのGitHub Releasesまたは案内しているF-Droidリポジトリから取得してください。第三者が再配布するAPKの安全性は確認できません。
:::

## 更新

- **F-Droid版**: F-Droidクライアントから更新できます。
- **GitHub版**: 新しいリリースのAPKをダウンロードし、上書きインストールします。

同じ署名の正規APKであれば、通常は設定やアプリ内データを保持したまま更新できます。
