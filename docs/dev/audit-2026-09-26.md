# ソースコード監査・修正記録（2026-09-26）

`git pull --ff-only origin main` 後の `1d9dfe6` を基準に、Android の認証・通信・設定保存・一覧状態・更新処理、および Rust の画像展開・署名検証を調査した。

## 確認した問題と修正

| 優先度 | 分類 | 問題と影響 | 修正 | 主な対象 |
| --- | --- | --- | --- | --- |

| 高 | セキュリティ | PallaSync の Ed25519 検証が弱い公開鍵を受理する。 | `verify_strict` を使用。通常の署名と既存の旧形式との互換性は回帰テストで確認。 | `rust/pallasync-core/src/crypto.rs` |

## 検証

- Android：`:app:testDebugUnitTest` 全165件成功（48スイート、失敗・スキップなし）。新規回帰テストでは URL 検証、本文読み取り失敗、キャンセル後の応答破棄、APK パス境界、キャッシュ競合、表示設定反映、設定移行の中断・復旧を確認。
- Kotlin：`:app:ktlintMainSourceSetCheck`、`:app:ktlintTestSourceSetCheck`、`:app:detekt`、`:app:checkQualityBaselineBudgets` 成功。既存の解析ベースラインは拡張していない。
- Rust Pixiv：`cargo test --all-features`（40件）、`cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings` 成功。
- Rust PallaSync：`cargo test`（5件）、`cargo fmt --check` 成功。厳格な clippy は既存の12件の指摘で失敗。既存の `collapsible_if`、`too_many_arguments`、`needless_borrows_for_generic_args` の3カテゴリのみ許可した再検証は成功。
- `git diff --check` 成功。

## 検証範囲の限界

- 接続済みの Android 端末・エミュレーターがないため、実際の Pixiv・Discord ログインと端末上の設定移行は未検証。
- `:app:assembleDebug` は Android NDK が未導入のため `buildRustAndroid` / `buildPallaSyncCoreAndroid` で停止。APK 全体の生成は未完了。
- 性能改善は不要なバッファ・タスク・キャッシュ削除を除く実装上の改善。端末上のメモリ量や処理時間のベンチマーク数値は測定していない。
- コード調査と回帰テストで確認できた問題を対象とした記録であり、全経路の動的検査や外部サービスの監査ではない。
