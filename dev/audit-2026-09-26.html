ソースコード監査・修正記録（2026-09-26） ​

git pull --ff-only origin main 後の 1d9dfe6 を基準に、Android の認証・通信・設定保存・一覧状態・更新処理、および Rust の画像展開・署名検証を調査した。

確認した問題と修正 ​

優先度分類問題と影響修正主な対象
高セキュリティPixiv ログインのリダイレクト判定がホスト名の部分一致を含み、想定外の URL を認証結果として扱う。階層構造を持たない URI では例外も起こり得る。許可したスキーム・ホスト・ポート・パスを検証し、不正・重複コードを拒否。WebView と Intent で同一のポリシーを使用。LoginUrlPolicy.kt、LoginScreens.kt、IllustiaAuthFeedModule.kt
高セキュリティDiscord ログインが URL の部分一致と任意の JavaScript alert をトークン取得に使用する。正確な HTTPS オリジンとアプリのパスを検証し、JavaScript 実行結果のコールバックで取得。画面終了時に WebView を破棄。DiscordLoginScreen.kt
高セキュリティPallaSync の Ed25519 検証が弱い公開鍵を受理する。verify_strict を使用。通常の署名と既存の旧形式との互換性は回帰テストで確認。rust/pallasync-core/src/crypto.rs
中性能・不具合アニメーション ZIP のフレームを丸ごとメモリに保持し、無制限に書き込みタスクを生成する。失敗・キャンセル時に一時ファイル削除と書き込みが競合する。既存の blocking worker 内で逐次ストリーミングし、一時ディレクトリの所有権を worker に保持。正規化後の重複エントリも拒否。rust/pixiv-api/src/ugoira.rs
中性能・不具合キャッシュへの並行追加で容量上限を超える。満杯のキャッシュで既存キーを更新すると無関係な応答も削除され、再通信が増える。更新操作を同期化し、既存キーの更新時は不要な退避を行わない。PixivApiCache.kt
中不具合HTTP ヘッダー受信後に本文の読み取りが失敗すると、例外がコールバックから漏れて待機中の coroutine に通知されない。IOException を呼び出し元に返し、応答を確実に閉じる。OkHttpAwait.kt
中不具合検索ページ蓄積中のキャンセルを握り潰し、古い検索結果を画面状態に反映する可能性がある。キャンセル例外を再送出。IllustiaAuthFeedModule.kt
中不具合全体の成人向けフィルターが無効だと、関連作品の表示設定変更が読み込み済み一覧に反映されない。関連作品の設定も早期 return の条件に含める。IllustListExtensions.kt
高データ保持設定スキーマ更新時に DataStore・Room の値が旧設定の既定値で置換され得る。暗号化ストアを使用できない場合、移行処理が保持すべきトークンも削除する。現在の保存先から値を引き継ぎ、移行を中断しても再試行可能な順序で保存。フォールバックの認証情報を保持し、暗号化ストア復旧後に移す。旧コピーの同期削除後に完了とする。SettingsStoreMigration.kt、SettingsStorePreferences.kt
中セキュリティAPK 更新ファイルの検証がパス文字列の前方一致のみで、同じ接頭辞を持つ隣接ディレクトリも許可する。正規化したパスのディレクトリ境界を検証。AppUpdaterRepository.kt
高開発環境の依存関係ドキュメント用の Vite 5 / esbuild、および nanoid に既知の問題が残っている。Vite を 6.4.3 に固定し、lockfile を更新。esbuild 0.25.12、nanoid 3.3.19 を解決。package.json、package-lock.json
高ベンチマークの依存関係AndroidX Benchmark が取り込む Wire 6.4.0 に Protobuf デコードの問題がある。Wire の共通・JVM モジュールに 6.4.5 の制約を追加。benchmark/build.gradle
高静的解析ツールの依存関係ビルドスクリプトの修正版固定が独立した ktlint / androidLintTool のクラスパスには届かず、Logback・Bouncy Castle・Commons Lang・HttpClient の古い版が使用される。既存のセキュリティ版設定を、該当するツールの構成にも限定して適用。build.gradle、既存の gradle.properties

検証 ​

  • Android：:app:testDebugUnitTest 全165件成功（48スイート、失敗・スキップなし）。新規回帰テストでは URL 検証、本文読み取り失敗、キャンセル後の応答破棄、APK パス境界、キャッシュ競合、表示設定反映、設定移行の中断・復旧を確認。
  • Kotlin：:app:ktlintMainSourceSetCheck、:app:ktlintTestSourceSetCheck、:app:detekt、:app:checkQualityBaselineBudgets 成功。既存の解析ベースラインは拡張していない。
  • Rust Pixiv：cargo test --all-features（40件）、cargo fmt --check、cargo clippy --all-targets --all-features -- -D warnings 成功。
  • Rust PallaSync：cargo test（5件）、cargo fmt --check 成功。厳格な clippy は既存の12件の指摘で失敗。既存の collapsible_if、too_many_arguments、needless_borrows_for_generic_args の3カテゴリのみ許可した再検証は成功。
  • git diff --check 成功。
  • ドキュメント：npm ci と npm run docs:build 成功。更新後の npm 監査は脆弱性0件。
  • 依存関係修正後にも Android 単体テスト・Kotlin 品質チェックが成功。:benchmark:compileBenchmarkReleaseKotlin 成功。dependencyInsight と依存関係レポートで Wire と静的解析ツールの修正版への切り替えを確認。
  • :app:lintDebug は修正版のツール依存関係で解析・レポート生成まで完了したが、ソースに対する211 errors / 346 warnings / 7 hints で失敗。既存の翻訳不足や Compose 使用法の指摘を含み、この監査で全件の解消は行っていない。依存関係の互換性エラーやメモリ不足による失敗はなかった。

依存関係の参照情報 ​

  • Vite：Windows のアクセス制御、UNC パス、ソースマップのパス検証。VitePress 1.6 系を維持し、同梱の Vue プラグインが許容する Vite 6 系の修正版に固定した。
  • esbuild：開発サーバーのクロスオリジン読み取り。
  • nanoid：カスタム生成器の停止性。
  • Wire：Protobuf の長さ検証。

GitHub が報告した14件を依存関係の解決結果と照合した。npm の4件と Wire の1件に加え、残る9件は次の独立したツールの構成に存在していた。ビルドスクリプト側の固定だけでは対処できていなかったため、この PR で適用先を追加した。

検証範囲の限界 ​

  • 接続済みの Android 端末・エミュレーターがないため、実際の Pixiv・Discord ログインと端末上の設定移行は未検証。
  • :app:assembleDebug は Android NDK が未導入のため buildRustAndroid / buildPallaSyncCoreAndroid で停止。APK 全体の生成は未完了。
  • Android Lint の全体チェックと、PallaSync の厳格 clippy は上記の既存指摘が残るため未通過。
  • 性能改善は不要なバッファ・タスク・キャッシュ削除を除く実装上の改善。端末上のメモリ量や処理時間のベンチマーク数値は測定していない。
  • コード調査と回帰テストで確認できた問題を対象とした記録であり、全経路の動的検査や外部サービスの監査ではない。
