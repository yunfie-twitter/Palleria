# Security Policy

## Supported Versions

Security fixes are provided for the current development branch and the latest released version line.

Older releases may not receive security updates. If possible, verify whether the issue still occurs on the latest development branch before reporting it.

## Reporting a Vulnerability

If you believe you have found a security issue in Illustia, please report it privately instead of opening a public issue.

This repository does not currently publish a dedicated security contact address. Please use the project's preferred private reporting channel, or contact a maintainer to request the current security contact before sharing sensitive details.

When reporting an issue, include as much relevant information as possible:

- A concise summary of the issue
- The affected version, branch, or commit, if known
- Clear steps to reproduce the issue
- Expected behavior and actual behavior
- Relevant logs, screenshots, or proof-of-concept material
- The Android version, device model, and build variant, if applicable
- The name and version of any affected third-party dependency, if applicable

Please avoid sharing credentials, API keys, personal data, or other sensitive information in your report.

## Public Disclosure

Please do not publicly disclose vulnerability details, reproduction steps, or exploit material until the maintainers have had an opportunity to review the report and coordinate an appropriate response.

## Response Expectations

After a report is received, the maintainers will aim to:

1. Acknowledge receipt of the report.
2. Review and validate the reported issue.
3. Develop and release a fix or mitigation if the issue is confirmed.
4. Coordinate the timing of any public disclosure with the reporter when practical.

## Scope

This policy covers security issues in the Illustia Android application and related repository assets.

Reports concerning third-party services or dependencies used by the application are also welcome. Please include the dependency name and version when available, along with any relevant upstream advisory or issue link if one exists.

## Non-Security Issues

For general bug reports, feature requests, usage questions, or non-security issues, please use the repository's regular issue tracker instead of the private security reporting channel.
